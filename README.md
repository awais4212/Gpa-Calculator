# 📊 GPA Calculator

> A comprehensive Java application for accurate student GPA computation

## ✨ Overview

The GPA Calculator is a robust Java program designed to streamline academic performance tracking. It computes a student's Grade Point Average by processing course marks and credit hours across seven courses, utilizing predefined grade ranges to deliver precise GPA calculations.

## 🎯 Features

- **Multi-Course Support** - Calculate GPA for up to seven courses simultaneously
- **Credit Hour Weighting** - Accurate calculations based on individual course credits
- **Grade Range Mapping** - Automatic conversion of numerical marks to letter grades
- **Instant Results** - Real-time GPA computation and display
- **User-Friendly Interface** - Intuitive input system for seamless data entry

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- Any Java-compatible IDE or command line interface

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/gpa-calculator.git
```

2. Navigate to the project directory
```bash
cd gpa-calculator
```

3. Compile the Java program
```bash
javac GpaCalculator.java
```

4. Run the application
```bash
java GpaCalculator
```

## 💡 How It Works

The calculator follows a straightforward process:

1. **Input Collection** - Enter marks (0-100) for each of the seven courses
2. **Credit Hours** - Specify credit hours assigned to each course
3. **Grade Conversion** - Marks are automatically mapped to grades using predefined ranges
4. **GPA Calculation** - The system computes weighted GPA based on credits
5. **Results Display** - Your final GPA is displayed with clear formatting

## 📝 Grade Scale

| Marks Range | Letter Grade | Grade Points |
|-------------|--------------|--------------|
| 90-100      | A            | 4.0          |
| 80-89       | B            | 3.0          |
| 70-79       | C            | 2.0          |
| 60-69       | D            | 1.0          |
| Below 60    | F            | 0.0          |
